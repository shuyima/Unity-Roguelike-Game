# Unity 2D 程序化地牢 Roguelike 游戏

一个基于 Unity 开发的 2D 程序化地牢 Roguelike 游戏，核心实现了程序化地牢生成与回合制战斗系统。

## 🎮 项目简介

本项目使用 Unity 2020.3 开发，核心实现了基于 **Prim 最小生成树** 和 **BFS 距离场** 的程序化地牢生成器，以及回合制战斗系统，旨在探索 Roguelike 游戏中关卡生成与战斗机制的设计与实现。

## ✨ 核心功能

### 程序化地牢生成
- 基于 **Prim 最小生成树** 连通房间，结合 **L 形走廊** 生成地牢布局
- 使用 **BFS 距离场** 选取距离最远的可达点作为出口，保证可达性
- 通过 **2400 组随机种子**（6 种地图尺寸）批量验证以下不变量：
  - 出口必定可达
  - 地面全连通
  - 边界不被挖穿

### BFS 距离场的复用
- **确定出口位置**：选取距离场中最远的可达点
- **筛选敌人出生点**：避开玩家出生半径
- **回溯主通路**：保证可破坏墙体不会堵死出口
- **保护墙体**：对墙体放置做保护，避免破坏后堵死通路

### 随机系统
- 基于 `System.Random` 实例构建统一随机源
- 怪物与道具放置全部复用，实现**同一种子复现同一张地图**

### 回合制战斗
- 基于**静态事件总线**解耦玩家与敌人
- 敌人采用**贪心寻路**（优先走差值较大的轴，受阻则换轴）
- 可在 L 形走廊中稳定绕行

## 🛠️ 技术栈

- **引擎**：Unity 2020.3
- **语言**：C#
- **核心模块**：Unity 2D 物理 / 程序化生成 / BFS / Prim / 事件总线 / 回合制系统
